# 🚦 Traffic Sign Detection using YOLOv8

A **Deep Learning based Traffic Sign Detection system** that uses **YOLOv8** to identify and classify traffic signs from images.  
The project also includes a **Flask web application** that allows users to upload images and detect traffic signs with bounding boxes and confidence scores.

---

## 📌 Features

- Detect traffic signs from images
- Bounding box detection with confidence score
- YOLOv8 object detection model
- Simple web interface using Flask
- Upload image and get instant predictions
- Custom trained model using traffic sign dataset

---

## 🧠 Technologies Used

- Python
- YOLOv8 (Ultralytics)
- Flask
- OpenCV
- NumPy
- HTML
- CSS
